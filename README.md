# streetviewer

Mapa de lugares para Android: murales, puntos panorámicos y estacionamientos. Todo queda en el teléfono.

- Mapa claro tipo Google Maps (OpenFreeMap; es lo único que usa internet).
- "Marcar punto": ubicás la marca y completás qué es, quién lo administra, hacia dónde mira y notas.
- Pines violetas = murales, verdes = panorámicos, azules = estacionamientos, con filtros por tipo.
- Tocá un punto para ver el detalle, cómo llegar, editarlo o eliminarlo.
- Buscador de direcciones (el de Android) y botón de mi ubicación.
- Menú ⋮ → Exportar / Importar puntos (archivo .json) para hacer copias o compartirlos.

Cada cambio en `main` se compila solo en GitHub Actions y se publica en **Releases**.
